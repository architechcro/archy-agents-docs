    Troubleshooting¶

    Find your symptom, apply the fix. When you contact support, include the request_id from the error body (or the X-Request-ID response header), the endpoint, and the time.

    Setup¶

    Symptom Cause Fix
    API not reachable on port 8000 Container still migrating, or crashed docker compose ps, then docker compose logs api
    500 when you create an LLM credential LLM_CREDENTIAL_ENCRYPTION_KEY is not set on the API Set a base64 32 byte key and restart (Run Archy locally)
    401 on every provisioning call The service token was signed with another JWT_SECRET_KEY Mint the token with the API's secret
    Provider URL rejected SSRF protection blocks private, loopback or http:// addresses Use a public https:// URL; for local Ollama the operator sets SSRF_ALLOW_LOCAL_URLS=true
    Invite link points to localhost PASSWORD_RESET_URL_BASE is the development default The operator sets it to your onboarding page

    Authentication and permissions¶

    Symptom Cause Fix
    401 Missing bearer token No Authorization header Send Authorization: Bearer <token>
    401 Invalid credentials Wrong email or password, or inactive user Reset the password or check the account
    401 Token revoked The password was reset, or the user was deactivated Log in again
    403 Forbidden on a tenant route org_id or project_id in the path differ from the token Use the ids from GET /tenancy/whoami or switch tenant
    403 Org admin role required The user is not an admin Use an admin (Roles)
    403 Service token required A user token was used on a provisioning route Use a service token
    403 Missing scopes: ... The service token lacks the scope Mint a token with it
    403 Not a member of this project Switching to a project without membership Provision the membership
    429 Rate limited Wait Retry-After seconds

    LLM providers¶

    Symptom Cause Fix
    verify returns success: false, "Authentication failed" Wrong key or base URL Update the credential, verify again
    422 Credential must be verified before attaching a model The credential is not verified Verify it first
    Agent replies Echo: ... with meta.mode = "echo" No model resolved Attach a model or pin config.model with a credential_id
    credential_error No usable credential and platform fallback is off Add, verify and attach a credential
    The agent uses the platform model, not mine config.model has model_name but no credential_id Add the credential_id, or use an attachment
    Embeddings fail for new knowledge bases The embedding default is missing, deleted or unverified PUT /llm-providers/embedding-default
    Azure 404 DeploymentNotFound model_name is not a deployment name Use the Azure deployment name

    Knowledge bases¶

    Symptom Cause Fix
    Upload rejected with "Unsupported file type" Extension not supported Convert to PDF, Word (.docx), Excel (.xlsx), PowerPoint (.pptx), text, Markdown, JSON, HTML, PNG or JPEG
    "File too large (max 50MB)" A file exceeds 50 MB Split it
    indexed_total is below files_total and indexing_total is 0 Some documents failed GET .../documents; read status; re-run POST .../index after fixing the embedding credential
    Queries return nothing Documents are not indexed yet, or the question does not match Check stats; try retrieval_strategy: "vector" or more specific wording
    Scanned PDF returns little text No text layer Provide text based files
    Results are poor after changing the embedding model Vectors from different models are not comparable Create a new knowledge base and re-ingest

    Agents¶

    Symptom Cause Fix
    400 Invalid config Unknown key or wrong type in config Read detail.errors[].loc; see the config reference
    Config settings disappeared after an update PUT replaced the whole config Send the complete config
    404 on a query with session_id Unknown or deleted session Omit session_id to start a new one
    Answers ignore the knowledge base knowledge_base_id missing, wrong project, or the KB has no indexed documents Check the config and stats
    Replies are cut off max_tokens too low Raise it
    Tool calls loop No max_iters or token_budget Set limits and refine the prompt

    Workflows¶

    Symptom Cause Fix
    422 config.agent_ids is required A legacy type is missing required config See the table in Workflows
    validate returns START_UNREACHABLE_END No path from start to an end Connect the graph
    validate returns TEMPLATE_NODE_NOT_UPSTREAM A template reads a node that runs later Reorder or read an earlier node
    400 Composite workflow must have a Start node on execute The graph has no start node. Saving did not reject it. Validate before you run
    422 with WORKFLOW_INPUTS_INVALID Missing or mistyped input Read detail.errors and fix inputs
    Run failed with MCP_UNAVAILABLE A required MCP server is down Check server health
    Run failed with SCHEMA_VALIDATION_FAILED The agent output did not match outputSchema Loosen the schema or tighten the prompt
    Status stays awaiting_input A checkpoint waits for an answer POST .../sessions/{session_id}/resume or /cancel
    Resume returns an error about inputs A sensitive input was not resent, or a non-sensitive one was sent Send only the declared sensitive inputs
    save-file node fails with a format error csv needs tabular data Use markdown, json or text, or produce a list of objects

    Streaming¶

    Symptom Cause Fix
    Nothing arrives until the end A proxy buffers the response Disable buffering for text/event-stream and raise idle timeouts
    EventSource fails with 401 It cannot send headers Use fetch with a ReadableStream
    The stream ends with event: error after a 200 A runtime failure Read data.detail and handle it in your client
    A dropped workflow stream Network interruption A stream cannot reattach to a run in progress. Start long jobs as asynchronous runs and poll

    Still stuck?¶

    1. Reproduce with curl and capture the full response (status, headers, body).
    2. Note the request_id.
    3. Check the API reference entry for the endpoint: required fields and roles are listed there.
    4. Contact your Archy operator with the endpoint, the request_id, the time and what you expected.
