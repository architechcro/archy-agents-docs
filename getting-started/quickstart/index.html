    Quickstart¶

    In this tutorial you create a complete tenant and a working agent that answers questions from your own document. You use the API only.

    You will:

    1. Provision an organization and a project.
    2. Create an organization admin and log in.
    3. Connect an LLM provider and choose the default models.
    4. Create a knowledge base and add a document.
    5. Create an agent grounded in the knowledge base and ask it a question.
    flowchart LR
    S[Service token] -->|1. provision| O[Organization and project]
    O -->|2. invite admin| A[Admin user token]
    A -->|3. credential and models| L[LLM provider]
    A -->|4. upload and index| K[Knowledge base]
    A -->|5. create| G[Agent]
    K --> G
    G -->|ask| R[Grounded answer]

    Before you start you need a running API (Run Archy locally), a SERVICE_TOKEN with scopes provision:org provision:project provision:user, and an OpenAI API key (any supported provider works; only the credential payload changes).

    export ARCHY_API_URL=http://localhost:8000
export SERVICE_TOKEN="<service token>"
export OPENAI_API_KEY="<your provider key>"

    1. Provision an organization and a project¶

    Provisioning endpoints are idempotent upserts: you choose the ids, and repeating the call changes nothing.

    export ORG_ID=$(uuidgen | tr 'A-Z' 'a-z')
export PROJECT_ID=$(uuidgen | tr 'A-Z' 'a-z')

curl -s -X PUT "$ARCHY_API_URL/api/v1/integrations/provisioning/orgs/$ORG_ID" \
  -H "Authorization: Bearer $SERVICE_TOKEN" -H "Content-Type: application/json" \
  -d '{"name": "Acme"}'

curl -s -X PUT "$ARCHY_API_URL/api/v1/integrations/provisioning/orgs/$ORG_ID/projects/$PROJECT_ID" \
  -H "Authorization: Bearer $SERVICE_TOKEN" -H "Content-Type: application/json" \
  -d '{"name": "Support", "description": "Customer support assistant"}'

    Each call returns {"org_id": "...", "created": true} (the project call also returns project_id).

    2. Create an admin and log in¶

    The invite endpoint creates the user, grants admin on the project, and returns a single-use set-password link. You use the token from the link to set a password, then log in.

    export ADMIN_EMAIL="admin@acme.example"
export ADMIN_PASSWORD="a-long-unique-passphrase"

INVITE=$(curl -s -X POST "$ARCHY_API_URL/api/v1/integrations/provisioning/orgs/$ORG_ID/admins/invite" \
  -H "Authorization: Bearer $SERVICE_TOKEN" -H "Content-Type: application/json" \
  -d "{\"email\": \"$ADMIN_EMAIL\"}")

RESET_TOKEN=$(echo "$INVITE" | jq -r '.invite_link' | sed 's/.*token=//')

curl -s -X POST "$ARCHY_API_URL/api/v1/auth/reset-password" \
  -H "Content-Type: application/json" \
  -d "{\"token\": \"$RESET_TOKEN\", \"new_password\": \"$ADMIN_PASSWORD\"}"

export ARCHY_TOKEN=$(curl -s -X POST "$ARCHY_API_URL/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d "{\"email\": \"$ADMIN_EMAIL\", \"password\": \"$ADMIN_PASSWORD\"}" | jq -r '.access_token')

    Confirm the token works:

    curl -s "$ARCHY_API_URL/api/v1/tenancy/whoami" -H "Authorization: Bearer $ARCHY_TOKEN"

    {
  "subject": "9e0eb3c6-63d5-42db-98cd-f2ed378ca051",
  "org_id": "35af6d8d-f874-4b2b-9222-122092075307",
  "project_id": "117c77c5-5c13-49b1-aad7-9499442d967c"
}

    From now on you use ARCHY_TOKEN. The service token is only for provisioning.

    Why not just register?

    POST /auth/register creates a user with its own organization in one call and is fine for experiments. That user has the permission-admin role and cannot create LLM credentials. See Roles.

    3. Connect an LLM provider¶

    Create the credential, then verify it. Verification makes a one token request to the provider. Only verified credentials are used at runtime.

    CRED_ID=$(curl -s -X POST "$ARCHY_API_URL/api/v1/llm-providers/credentials" \
  -H "Authorization: Bearer $ARCHY_TOKEN" -H "Content-Type: application/json" \
  -d "{\"provider\": \"openai\", \"display_name\": \"OpenAI\", \"api_key\": \"$OPENAI_API_KEY\", \"is_default\": true}" \
  | jq -r '.id')

curl -s -X POST "$ARCHY_API_URL/api/v1/llm-providers/credentials/$CRED_ID/verify" \
  -H "Authorization: Bearer $ARCHY_TOKEN"

    A successful verification returns {"success": true, "is_verified": true, "verified_at": "...", "latency_ms": 412, "error": null}. A wrong key returns success: false with an error message and nothing is attached.

    Now choose which models run by default. One attachment sets the chat model for the whole organization, and one sets the embedding model used by new knowledge bases:

    curl -s -X PUT "$ARCHY_API_URL/api/v1/llm-providers/model-attachments/org" \
  -H "Authorization: Bearer $ARCHY_TOKEN" -H "Content-Type: application/json" \
  -d "{\"credential_id\": \"$CRED_ID\", \"model_name\": \"gpt-4o-mini\"}"

curl -s -X PUT "$ARCHY_API_URL/api/v1/llm-providers/embedding-default" \
  -H "Authorization: Bearer $ARCHY_TOKEN" -H "Content-Type: application/json" \
  -d "{\"credential_id\": \"$CRED_ID\", \"model_name\": \"text-embedding-3-small\", \"dimensions\": 1536}"

    Verify first

    The model attachment call returns 422 Credential must be verified before attaching a model if verification did not succeed. Fix the key first.

    4. Create a knowledge base and add a document¶

    BASE="$ARCHY_API_URL/api/v1/orgs/$ORG_ID/projects/$PROJECT_ID"

export KB_ID=$(curl -s -X POST "$BASE/knowledge-bases" \
  -H "Authorization: Bearer $ARCHY_TOKEN" -H "Content-Type: application/json" \
  -d '{"name": "handbook", "description": "Company handbook"}' | jq -r '.id')

cat > handbook.md <<'EOF'
# Acme handbook

Support hours are 08:00 to 18:00 CET, Monday to Friday.
Refunds are available within 30 days of purchase with a receipt.
Enterprise customers get a named contact and a four hour response target.
EOF

curl -s -X POST "$BASE/knowledge-bases/$KB_ID/documents/upload" \
  -H "Authorization: Bearer $ARCHY_TOKEN" \
  -F "files=@handbook.md"

    Upload stores the file and enqueues indexing. Check progress until indexed_total equals files_total:

    curl -s "$BASE/knowledge-bases/$KB_ID/stats" -H "Authorization: Bearer $ARCHY_TOKEN"
# {"files_total": 1, "indexed_total": 1, "indexing_total": 0}

    Search it directly:

    curl -s -X POST "$BASE/knowledge-bases/$KB_ID/query" \
  -H "Authorization: Bearer $ARCHY_TOKEN" -H "Content-Type: application/json" \
  -d '{"query": "How long do I have to ask for a refund?", "top_k": 3}' | jq '.results[0].content'

    5. Create an agent and ask it a question¶

    export AGENT_ID=$(curl -s -X POST "$BASE/agents" \
  -H "Authorization: Bearer $ARCHY_TOKEN" -H "Content-Type: application/json" \
  -d "{
    \"name\": \"support-assistant\",
    \"description\": \"Answers support questions from the handbook\",
    \"config\": {
      \"sys_prompt\": \"You are a support assistant. Answer only from the knowledge base and say when you do not know.\",
      \"knowledge_base_id\": \"$KB_ID\",
      \"knowledge_base_top_k\": 4,
      \"temperature\": 0.2
    }
  }" | jq -r '.id')

curl -s -X POST "$ARCHY_API_URL/api/v1/agents/$AGENT_ID/query" \
  -H "Authorization: Bearer $ARCHY_TOKEN" -H "Content-Type: application/json" \
  -d '{"message": "What are your support hours and what is the refund window?"}'

    The response contains the answer and the session id. Pass session_id on the next call to continue the conversation.

    {
  "agent_id": "26fc2a0e-afe5-4c01-849b-eac03777464e",
  "session_id": "4e7c87f4-30d4-565f-a47b-9b4fca7f385a",
  "output": "Support hours are 08:00 to 18:00 CET, Monday to Friday. Refunds are available within 30 days of purchase with a receipt.",
  "meta": {}
}

    You now have an organization, an admin, a connected model, an indexed knowledge base and a grounded agent.

    The same flow in Python¶

    import os
import time
import uuid
from urllib.parse import parse_qs, urlparse

import httpx

BASE = os.environ.get("ARCHY_API_URL", "http://localhost:8000")
SERVICE = {"Authorization": f"Bearer {os.environ['SERVICE_TOKEN']}"}
PASSWORD = "a-long-unique-passphrase"

client = httpx.Client(base_url=BASE, timeout=120)


def ok(response: httpx.Response) -> dict | list:
    response.raise_for_status()
    return response.json()


# 1. Provision
org_id, project_id = str(uuid.uuid4()), str(uuid.uuid4())
ok(client.put(f"/api/v1/integrations/provisioning/orgs/{org_id}", headers=SERVICE, json={"name": "Acme"}))
ok(client.put(
    f"/api/v1/integrations/provisioning/orgs/{org_id}/projects/{project_id}",
    headers=SERVICE,
    json={"name": "Support"},
))

# 2. Admin: invite, set password, log in
invite = ok(client.post(
    f"/api/v1/integrations/provisioning/orgs/{org_id}/admins/invite",
    headers=SERVICE,
    json={"email": "admin@acme.example"},
))
reset_token = parse_qs(urlparse(invite["invite_link"]).query)["token"][0]
ok(client.post("/api/v1/auth/reset-password", json={"token": reset_token, "new_password": PASSWORD}))
login = ok(client.post("/api/v1/auth/login", json={"email": "admin@acme.example", "password": PASSWORD}))
user = {"Authorization": f"Bearer {login['access_token']}"}

# 3. LLM provider and default models
cred = ok(client.post(
    "/api/v1/llm-providers/credentials",
    headers=user,
    json={"provider": "openai", "display_name": "OpenAI", "api_key": os.environ["OPENAI_API_KEY"], "is_default": True},
))
verified = ok(client.post(f"/api/v1/llm-providers/credentials/{cred['id']}/verify", headers=user))
assert verified["success"], verified["error"]
ok(client.put(
    "/api/v1/llm-providers/model-attachments/org",
    headers=user,
    json={"credential_id": cred["id"], "model_name": "gpt-4o-mini"},
))
ok(client.put(
    "/api/v1/llm-providers/embedding-default",
    headers=user,
    json={"credential_id": cred["id"], "model_name": "text-embedding-3-small", "dimensions": 1536},
))

# 4. Knowledge base
scope = f"/api/v1/orgs/{org_id}/projects/{project_id}"
kb = ok(client.post(f"{scope}/knowledge-bases", headers=user, json={"name": "handbook"}))
ok(client.post(
    f"{scope}/knowledge-bases/{kb['id']}/documents/upload",
    headers=user,
    files=[("files", ("handbook.md", b"Refunds are available within 30 days of purchase.", "text/markdown"))],
))
while True:
    stats = ok(client.get(f"{scope}/knowledge-bases/{kb['id']}/stats", headers=user))
    if stats["indexed_total"] >= stats["files_total"] > 0:
        break
    time.sleep(2)

# 5. Agent
agent = ok(client.post(
    f"{scope}/agents",
    headers=user,
    json={
        "name": "support-assistant",
        "config": {"sys_prompt": "Answer only from the knowledge base.", "knowledge_base_id": kb["id"]},
    },
))
answer = ok(client.post(
    f"/api/v1/agents/{agent['id']}/query", headers=user, json={"message": "What is the refund window?"}
))
print(answer["output"])
