    Research and write pipeline¶

    You will build a composite workflow that researches a topic from two sources in parallel, merges the notes, writes a post, has a reviewer check it, and saves the final text as a file. You run it asynchronously and download the result.

    flowchart LR
    S((start)) --> RD[research_docs]
    S --> RW[research_web]
    RD --> M[merge: notes]
    RW --> M
    M --> W[draft]
    W --> V[review]
    V --> C{approved?}
    C -- yes --> F1[save_approved]
    C -- no --> RV[revise]
    RV --> F2[save_revised]
    F1 --> E((end))
    F2 --> E

    Prepare: the Quickstart done, optionally a knowledge base for the docs researcher, and the variables from the support assistant tutorial (archy.py).

    1. Create the agents¶

    Four agents with narrow roles beat one agent with a long prompt.

    # agents.py
import os

from archy import SCOPE, client

KB_ID = os.environ.get("KB_ID")  # optional


def agent(name: str, prompt: str, **config) -> str:
    r = client.post(f"{SCOPE}/agents", json={"name": name, "config": {"sys_prompt": prompt, "temperature": 0.3, **config}})
    r.raise_for_status()
    return r.json()["id"]


ids = {
    "docs": agent(
        "researcher-docs",
        "You research from the internal knowledge base only. Return short bullet facts with the source file name.",
        **({"knowledge_base_id": KB_ID} if KB_ID else {}),
    ),
    "web": agent(
        "researcher-web",
        "You research recent public information. Return short bullet facts with URLs.",
        web_search={"enabled": True, "provider": "duckduckgo"},
    ),
    "writer": agent("writer", "You write clear, accurate blog posts in Markdown. Never invent facts."),
    "reviewer": agent(
        "reviewer",
        "You review drafts for accuracy and clarity. Answer with JSON: approved (boolean) and feedback (string).",
        temperature=0,
    ),
}
print(ids)

    2. Define the graph¶

    Notes for reading the definition:

    • inputs declares what a caller must pass. topic is required; audience has a default.
    • variables holds constants, read as vars.max_words.
    • The reviewer has an outputSchema, so its answer is validated JSON. The condition node receives that JSON as its input and its field (approved) is a key of that JSON object, not a template.
    • A template may only read nodes that run before it. The revise node reads both draft and review, which are upstream of it.
    # workflow.py
from agents import ids
from archy import SCOPE, client


def node(id_, type_, **data):
    return {"id": id_, "type": type_, "data": data}


def edge(id_, source, target, **extra):
    return {"id": id_, "source": source, "target": target, **extra}


definition = {
    "version": 2,
    "inputs": [
        {"name": "topic", "type": "string", "required": True, "description": "What to write about"},
        {"name": "audience", "type": "string", "required": False, "default": "engineers"},
    ],
    "variables": {"max_words": 600},
    "graph": {
        "nodes": [
            node("start", "start"),
            node("r1", "agent", name="research_docs", agentId=ids["docs"],
                 prompt="Using the knowledge base, collect facts about {{input.topic}}."),
            node("r2", "agent", name="research_web", agentId=ids["web"],
                 prompt="Search the web for recent developments about {{input.topic}}."),
            node("m", "merge", name="notes", strategy="summarize",
                 instruction="Combine both sets of notes. Keep sources."),
            node("w", "agent", name="draft", agentId=ids["writer"],
                 prompt="Write a post of at most {{vars.max_words}} words for {{input.audience}} from these notes:\n{{nodes.notes.output}}"),
            node("v", "agent", name="review", agentId=ids["reviewer"],
                 prompt="Review this draft for accuracy and clarity:\n{{nodes.draft.output}}",
                 outputSchema={"type": "object",
                               "properties": {"approved": {"type": "boolean"}, "feedback": {"type": "string"}},
                               "required": ["approved", "feedback"]}),
            node("c", "condition", name="gate", field="approved", operator="equals", value="true"),
            node("rev", "agent", name="revise", agentId=ids["writer"],
                 prompt="Improve the draft using this feedback.\nDraft:\n{{nodes.draft.output}}\nFeedback: {{nodes.review.json.feedback}}"),
            node("s1", "save-file", name="save_approved", format="markdown", fileName="post",
                 source="node", sourceNodeId="w"),
            node("s2", "save-file", name="save_revised", format="markdown", fileName="post"),
            node("end", "end"),
        ],
        "edges": [
            edge("e1", "start", "r1"),
            edge("e2", "start", "r2"),
            edge("e3", "r1", "m", targetHandle="target-top-1"),
            edge("e4", "r2", "m", targetHandle="target-top-2"),
            edge("e5", "m", "w"),
            edge("e6", "w", "v"),
            edge("e7", "v", "c"),
            edge("e8", "c", "s1", sourceHandle="source-true", data={"connectionType": "route", "condition": "yes"}),
            edge("e9", "c", "rev", sourceHandle="source-false", data={"connectionType": "route", "condition": "no"}),
            edge("e10", "rev", "s2"),
            edge("e11", "s1", "end"),
            edge("e12", "s2", "end"),
        ],
    },
}

created = client.post(f"{SCOPE}/workflows", json={"name": "research-and-write", "type": "composite", "config": definition})
created.raise_for_status()
workflow_id = created.json()["id"]

report = client.post(f"{SCOPE}/workflows/{workflow_id}/validate", json={}).json()
print("valid:", report["valid"], report["errors"], report["warnings"])
print("workflow", workflow_id)

    Both the saved definition and any unsaved draft can be checked with validate. A typical mistake is reading nodes.review from a node that runs before the review; validation reports TEMPLATE_NODE_NOT_UPSTREAM.

    3. Run it asynchronously¶

    A run with two research steps, a merge and a review can take minutes, so start it in the background and poll.

    # run.py
import sys
import time

from archy import SCOPE, client

workflow_id = sys.argv[1]
started = client.post(
    f"{SCOPE}/workflows/{workflow_id}/runs",
    json={"message": "Write the post", "inputs": {"topic": "vector databases", "audience": "backend engineers"}},
)
started.raise_for_status()
run_id = started.json()["run_id"]
print("run", run_id)

while True:
    run = client.get(f"{SCOPE}/workflows/{workflow_id}/runs/{run_id}").json()
    print(run["status"])
    if run["status"] in ("succeeded", "failed"):
        break
    time.sleep(3)

if run["status"] == "failed":
    raise SystemExit(run["error"])

print(run["output"])

files = client.get(f"{SCOPE}/artifacts", params={"session_id": run["session_id"]}).json()["items"]
for artifact in files:
    content = client.get(f"{SCOPE}/artifacts/{artifact['id']}/download")
    open(artifact["name"], "wb").write(content.content)
    print("saved", artifact["name"])

    run["audit"] lists what each step did. For per-node timing and messages read the session: GET .../workflows/{id}/sessions/{session_id}.

    4. Watch it live (optional)¶

    Use the streaming endpoint to show progress in a UI. The unified trace events node.started and node.completed tell you which node is running. See Running and streaming.

    5. Iterate safely¶

    • Change a prompt or an edge with PUT .../workflows/{id}. Each update stores a version snapshot; to roll back, read the old version (GET .../versions/{n}) and PUT its config back.
    • Add a human gate between review and the save nodes with a checkpoint node: Human approval checkpoint.
    • Pass the result on: a storage-write node can write the file into a connected Drive folder, and the artifact can be downloaded by your application.

    What you learned¶

    You combined parallel agents, a merge, structured output, a conditional branch and file output in one workflow, validated it before running, and executed it as a background run.
