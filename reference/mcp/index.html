    MCP servers and tokens¶

    Register external MCP servers for agents and manage tokens for the Archy Platform MCP server.

    This page documents 28 endpoint(s). Replace $ARCHY_API_URL and $ARCHY_TOKEN as described in Conventions.

    Besides the responses listed for each endpoint, any endpoint can return 401 (missing or invalid token), 403 (wrong tenant, role or scope) and 404 (resource not found in your tenant). See Errors.

    GET /api/v1/mcp/status MCP router status
    GET /api/v1/orgs/{org_id}/projects/{project_id}/mcp-servers List MCP servers
    POST /api/v1/orgs/{org_id}/projects/{project_id}/mcp-servers Create MCP server
    GET /api/v1/orgs/{org_id}/projects/{project_id}/mcp-servers/{server_id} Get MCP server
    PUT /api/v1/orgs/{org_id}/projects/{project_id}/mcp-servers/{server_id} Update MCP server
    PATCH /api/v1/orgs/{org_id}/projects/{project_id}/mcp-servers/{server_id} Patch MCP server instance config
    DELETE /api/v1/orgs/{org_id}/projects/{project_id}/mcp-servers/{server_id} Delete MCP server
    POST /api/v1/orgs/{org_id}/projects/{project_id}/agents/{agent_id}/mcp-servers/{server_id}/attach Attach MCP server to agent
    POST /api/v1/orgs/{org_id}/projects/{project_id}/agents/{agent_id}/mcp-servers/{server_id}/detach Detach MCP server from agent
    GET /api/v1/orgs/{org_id}/projects/{project_id}/agents/{agent_id}/mcp-servers List agent MCP servers
    GET /api/v1/orgs/{org_id}/projects/{project_id}/mcp-servers/{server_id}/health Get MCP server health history

    POST /api/v1/orgs/{org_id}/projects/{project_id}/mcp-servers/{server_id}/health/check Trigger manual health check

    GET /api/v1/orgs/{org_id}/projects/{project_id}/mcp/tool-invocations/metrics Get MCP invocation metrics

    GET /api/v1/orgs/{org_id}/projects/{project_id}/mcp/tool-invocations List MCP tool invocations

    GET /api/v1/orgs/{org_id}/projects/{project_id}/mcp/tools Get MCP tool catalog

    GET /api/v1/mcp/status¶

    MCP router status

    Use case: lightweight check that the MCP management router is reachable.

    Authentication: none (public).

    Example

    curl -X GET "$ARCHY_API_URL/api/v1/mcp/status"

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]

response = httpx.request("GET", f"{BASE_URL}/api/v1/mcp/status", timeout=60)
response.raise_for_status()
print(response.json())

    Responses

    Status Description Body
    200 Successful Response StatusResponse

    Example 200 response:

    {
  "status": "completed"
}

    List MCP servers

    Use case: list all MCP servers configured for the project so clients can show attachment options.

    Auth: Bearer JWT; org_id and project_id must match token tenancy.

    Parameters

    Name In Type Required Description
    org_id path string (uuid) yes Organization id.
    project_id path string (uuid) yes Project id.

    Example

    curl -X GET "$ARCHY_API_URL/api/v1/orgs/$ORG_ID/projects/$PROJECT_ID/mcp-servers" \
  -H "Authorization: Bearer $ARCHY_TOKEN"

import httpx

    POST /api/v1/orgs/{org_id}/projects/{project_id}/mcp-servers¶

    Create MCP server

    Use case: register a new MCP server configuration in a project.

    After creation, attach the server to one or more agents so they can call MCP tools during execution.

    Auth: Bearer JWT; org_id and project_id must match token tenancy.

    Parameters

    Name In Type Required Description
    org_id path string (uuid) yes Organization id.
    project_id path string (uuid) yes Project id.

    Request body (application/json, required)

    Field Type Required Description
    name string yes (min length 1, max length 255)
    transport string yes (min length 1, max length 50)
    config object no
    template_id string (uuid) no
    instance_label string no

    Schema: McpServerCreate

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/orgs/$ORG_ID/projects/$PROJECT_ID/mcp-servers" \
  -H "Authorization: Bearer $ARCHY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "name": "example-name",
  "transport": "string"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
HEADERS = {"Authorization": f"Bearer {os.environ['ARCHY_TOKEN']}"}
ORG_ID = "<org_id>"
PROJECT_ID = "<project_id>"

payload = {
    "name": "example-name",
    "transport": "string"
}

response = httpx.request("POST", f"{BASE_URL}/api/v1/orgs/{ORG_ID}/projects/{PROJECT_ID}/mcp-servers", headers=HEADERS, json=payload, timeout=60)
response.raise_for_status()
print(response.json())

    Responses

    Status Description Body
    200 Successful Response McpServerResponse
    422 Validation Error HTTPValidationError

    Example 200 response:

    {
  "id": "45bdc47f-1b35-50cf-a399-28ac85d671c3",
  "project_id": "d94f2d78-6b95-55e1-ab9e-92b128bed100",
