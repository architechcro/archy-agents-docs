    Sessions and artifacts¶

    Conversation and run history, and files produced by runs.

    This page documents 14 endpoint(s). Replace $ARCHY_API_URL and $ARCHY_TOKEN as described in Conventions.

    Besides the responses listed for each endpoint, any endpoint can return 401 (missing or invalid token), 403 (wrong tenant, role or scope) and 404 (resource not found in your tenant). See Errors.

    Method Path Summary
    GET /api/v1/orgs/{org_id}/projects/{project_id}/artifacts List artifacts
    POST /api/v1/orgs/{org_id}/projects/{project_id}/artifacts Upload an artifact

    GET /api/v1/orgs/{org_id}/projects/{project_id}/artifacts¶

    List artifacts

    Authentication: bearer token in the Authorization header.

    Parameters

    Name In Type Required Description
    org_id path string (uuid) yes Organization id.
    project_id path string (uuid) yes Project id.
    run_id query string (uuid) no Run id.
    node_id query string no
    session_id query string (uuid) no Session id.
    media_type query string no Media type prefix, e.g. image/
    source query string no
    limit query integer no (min 1, max 200, default 50)
    offset query integer no (min 0, default 0)

    Example

    curl -X GET "$ARCHY_API_URL/api/v1/orgs/$ORG_ID/projects/$PROJECT_ID/artifacts" \
  -H "Authorization: Bearer $ARCHY_TOKEN"

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
HEADERS = {"Authorization": f"Bearer {os.environ['ARCHY_TOKEN']}"}
ORG_ID = "<org_id>"
PROJECT_ID = "<project_id>"

response = httpx.request("GET", f"{BASE_URL}/api/v1/orgs/{ORG_ID}/projects/{PROJECT_ID}/artifacts", headers=HEADERS, timeout=60)
response.raise_for_status()
print(response.json())

    POST /api/v1/orgs/{org_id}/projects/{project_id}/workflows/{workflow_id}/runs/{run_id}/exports¶

    Export a run or node output as a file

    Stores the output of a finished run (source: run) or of one node (source: node, with nodeId) as an artifact in the given format. Errors: run_not_found, run_not_finished, node_output_not_found, export_format_unknown, export_format_not_supported_for_output, export_input_too_large, export_output_empty, export_value_not_finite, and the artifact limit codes.

    Authentication: bearer token in the Authorization header.

    Parameters

    Name In Type Required Description
    org_id path string (uuid) yes Organization id.
    project_id path string (uuid) yes Project id.
    workflow_id path string (uuid) yes Workflow id.
    run_id path string (uuid) yes Run id.

    Request body (application/json, required)

    Field Type Required Description
    source enum: run, node yes
    nodeId string no
    format string yes (max length 32)
    name string no

    Schema: RunExportRequest

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/orgs/$ORG_ID/projects/$PROJECT_ID/workflows/$WORKFLOW_ID/runs/$RUN_ID/exports" \
  -H "Authorization: Bearer $ARCHY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "source": "run",
  "format": "string"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
HEADERS = {"Authorization": f"Bearer {os.environ['ARCHY_TOKEN']}"}
ORG_ID = "<org_id>"
PROJECT_ID = "<project_id>"
WORKFLOW_ID = "<workflow_id>"
RUN_ID = "<run_id>"

payload = {
    "source": "run",
    "format": "string"
}

response = httpx.request("POST", f"{BASE_URL}/api/v1/orgs/{ORG_ID}/projects/{PROJECT_ID}/workflows/{WORKFLOW_ID}/runs/{RUN_ID}/exports", headers=HEADERS, json=payload, timeout=60)
response.raise_for_status()
print(response.json())
