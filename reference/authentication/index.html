    Authentication and tenancy¶

    Register, log in, reset passwords, inspect or switch the active tenant and the OAuth server used by hosted MCP clients.

    This page documents 12 endpoint(s). Replace $ARCHY_API_URL and $ARCHY_TOKEN as described in Conventions.

    Besides the responses listed for each endpoint, any endpoint can return 401 (missing or invalid token), 403 (wrong tenant, role or scope) and 404 (resource not found in your tenant). See Errors.

    Method Path Summary
    POST /api/v1/auth/register Register user
    POST /api/v1/auth/login Login
    POST /api/v1/auth/forgot-password Forgot password
    POST /api/v1/auth/reset-password Reset password
    GET /api/v1/tenancy/whoami Resolve tenancy context
    GET /api/v1/tenancy/orgs List organizations available to the current user
    GET /api/v1/tenancy/projects List projects available to the current user in an org
    POST /api/v1/tenancy/switch Switch the active org/project for the current user
    POST /oauth/register Dynamic Client Registration
    GET /oauth/authorize OAuth Authorization
    POST /oauth/token Token Exchange
    POST /oauth/revoke Revoke Token (RFC 7009)

    POST /api/v1/auth/register¶

    Register user

    Use case: create a new user and seed an initial org + project for them, returning a bearer JWT.

    The returned JWT encodes org_id and project_id for multi-tenant scoping across the API.

    Authentication: none (public).

    Request body (application/json, required)

    Field Type Required Description
    email string (email) yes
    password string yes (min length 8, max length 128)
    org_name string no (min length 1, max length 255, default "Default Org")
    project_name string no (min length 1, max length 255, default "Default Project")

    Schema: RegisterRequest

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
  "email": "dev@example.com",
  "password": "a-long-unique-passphrase"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]

payload = {
    "email": "dev@example.com",
    "password": "a-long-unique-passphrase"
}

response = httpx.request("POST", f"{BASE_URL}/api/v1/auth/register", json=payload, timeout=60)
response.raise_for_status()
print(response.json())

    Responses

    Status Description Body
    200 Successful Response src__schemas__auth__TokenResponse
    422 Validation Error HTTPValidationError

    Example 200 response:

    {
  "access_token": "string",
  "user_id": "ed5ae942-97ce-5488-be42-b7ee378bdc6d",
  "org_id": "7c6b93cc-e828-515a-bb79-2f9e333b65ae",
  "project_id": "d94f2d78-6b95-55e1-ab9e-92b128bed100"
}

    POST /api/v1/auth/login¶

    Login

    Use case: authenticate an existing user and obtain a bearer JWT for subsequent API calls.

    The returned JWT encodes org_id and project_id for multi-tenant scoping across the API.

    Authentication: none (public).

    Request body (application/json, required)

    Field Type Required Description
    email string (email) yes
    password string yes (min length 8, max length 128)
    remember_me boolean no (default false)

    Schema: LoginRequest

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
  "email": "dev@example.com",
  "password": "a-long-unique-passphrase"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]

payload = {
    "email": "dev@example.com",
    "password": "a-long-unique-passphrase"
}

response = httpx.request("POST", f"{BASE_URL}/api/v1/auth/login", json=payload, timeout=60)

    POST /api/v1/auth/forgot-password¶

    Forgot password

    Generate a password reset token and send an email with a reset link.

    Security: always returns 200 and does not reveal whether the email is registered.

    Authentication: none (public).

    Request body (application/json, required)

    Field Type Required Description
    email string (email) yes

    Schema: ForgotPasswordRequest

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/auth/forgot-password" \
  -H "Content-Type: application/json" \
  -d '{
  "email": "dev@example.com"
}'

response = httpx.request("POST", f"{BASE_URL}/api/v1/auth/forgot-password", json=payload, timeout=60)

    GET /api/v1/tenancy/whoami¶

    Resolve tenancy context

    Use case: verify that authentication and tenant resolution is working.

    Returns the subject + org_id + project_id derived from the bearer JWT.

    Authentication: bearer token in the Authorization header.

    Parameters

    Name In Type Required Description
    org_id query string (uuid) no Organization id.
    project_id query string (uuid) no Project id.

    Example

    curl -X GET "$ARCHY_API_URL/api/v1/tenancy/whoami" \
  -H "Authorization: Bearer $ARCHY_TOKEN"

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
HEADERS = {"Authorization": f"Bearer {os.environ['ARCHY_TOKEN']}"}

response = httpx.request("GET", f"{BASE_URL}/api/v1/tenancy/whoami", headers=HEADERS, timeout=60)
response.raise_for_status()
print(response.json())

    Responses

    Status Description Body
    200 Successful Response WhoAmIResponse
    422 Validation Error HTTPValidationError

    Example 200 response:

    {
  "subject": "string",
  "org_id": "7c6b93cc-e828-515a-bb79-2f9e333b65ae",
  "project_id": "d94f2d78-6b95-55e1-ab9e-92b128bed100"

    POST /oauth/register¶

    Dynamic Client Registration

    Register a new OAuth client for MCP authorization (RFC 7591). Public clients (VS Code, CLI) use PKCE and set token_endpoint_auth_method='none'.

    Authentication: none (public).

    Request body (application/json, required)

    Field Type Required Description
    client_name string yes (min length 1, max length 255)
    redirect_uris array of string yes (min items 1)
    grant_types array of string no
    token_endpoint_auth_method string no (default "none")
    scope string no (default "mcp:tools")

    Schema: ClientRegistrationRequest

    Example

    curl -X POST "$ARCHY_API_URL/oauth/register" \
  -H "Content-Type: application/json" \
  -d '{
  "client_name": "string",
  "redirect_uris": [
    "string"
  ]
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]

payload = {
    "client_name": "string",
    "redirect_uris": [
        "string"
    ]
}

response = httpx.request("POST", f"{BASE_URL}/oauth/register", json=payload, timeout=60)
response.raise_for_status()
print(response.json())

    Responses

    Status Description Body
    201 Successful Response ClientRegistrationResponse
    422 Validation Error HTTPValidationError

    Example 201 response:

    {

    "string"

    GET /oauth/authorize¶

    OAuth Authorization

    Redirect users here to authorize MCP client access. Renders a consent page.

    Authentication: none (public).

    Parameters

    Name In Type Required Description
    response_type query string yes
    client_id query string yes
    redirect_uri query string yes
    code_challenge query string yes
    code_challenge_method query string no (default "S256")
    scope query string no (default "mcp:tools")
    state query string no

    Example

    curl -X GET "$ARCHY_API_URL/oauth/authorize?response_type=$RESPONSE_TYPE&client_id=$CLIENT_ID&redirect_uri=$REDIRECT_URI&code_challenge=$CODE_CHALLENGE"

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
RESPONSE_TYPE = "<response_type>"
CLIENT_ID = "<client_id>"
REDIRECT_URI = "<redirect_uri>"
CODE_CHALLENGE = "<code_challenge>"

response = httpx.request("GET", f"{BASE_URL}/oauth/authorize", params={"response_type": RESPONSE_TYPE, "client_id": CLIENT_ID, "redirect_uri": REDIRECT_URI, "code_challenge": CODE_CHALLENGE}, timeout=60)
response.raise_for_status()
print(response.json())

    Responses

    Status Description Body
    200 Successful Response text/html
    422 Validation Error HTTPValidationError

    POST /oauth/token¶

    Token Exchange

    Exchange an authorization code for a long-lived MCP access token. Accepts application/x-www-form-urlencoded per RFC 6749. Requires PKCE code_verifier that matches the code_challenge from authorization.

    Authentication: none (public).

    Parameters

    Name In Type Required Description
    authorization header string no

    Request body (application/x-www-form-urlencoded, required)

    Field Type Required Description
    grant_type string yes
    code string yes
    redirect_uri string yes
    code_verifier string yes
    client_id string no

    Schema: Body_token_exchange_oauth_token_post

    Example

    curl -X POST "$ARCHY_API_URL/oauth/token" \
  -H "Content-Type: application/json" \
  -d '{
  "grant_type": "string",
  "code": "string",
  "redirect_uri": "string",
  "code_verifier": "string"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]

payload = {
    "grant_type": "string",
    "code": "string",
    "redirect_uri": "string",
    "code_verifier": "string"
}

response = httpx.request("POST", f"{BASE_URL}/oauth/token", json=payload, timeout=60)
response.raise_for_status()
print(response.json())

    Responses

    Status Description Body
    200 Successful Response src__api__v1__routes__oauth__TokenResponse
    422 Validation Error HTTPValidationError

    Example 200 response:

    {
  "access_token": "string"
}

    POST /oauth/revoke¶

    Revoke Token (RFC 7009)

    Revoke an MCP access token. Accepts application/x-www-form-urlencoded per RFC 7009. Always returns 200.

    Authentication: none (public).

    Request body (application/x-www-form-urlencoded, required)

    Field Type Required Description
    token string yes
    token_type_hint string no

    Schema: Body_revoke_token_oauth_revoke_post

    Example

    curl -X POST "$ARCHY_API_URL/oauth/revoke" \
  -H "Content-Type: application/json" \
  -d '{
  "token": "<token>"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]

payload = {
    "token": "<token>"
}

response = httpx.request("POST", f"{BASE_URL}/oauth/revoke", json=payload, timeout=60)
response.raise_for_status()
print(response.json())
