    POST /api/v1/orgs/{org_id}/projects/{project_id}/connections/oauth/start¶

    Start OAuth connect

    Authentication: bearer token in the Authorization header.

    Parameters

    Name In Type Required Description
    org_id path string (uuid) yes Organization id.
    project_id path string (uuid) yes Project id.

    Request body (application/json, required)

    Field Type Required Description
    provider string yes (min length 1, max length 32)
    kind enum: storage, database no (default "storage")
    scope enum: user, project, org yes
    name string no
    scopes array of string no (max items 20)
    return_to string no
    redirect_uri string yes (min length 1, max length 512)
    connection_id string (uuid) no

    Schema: OAuthStartRequest

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/orgs/$ORG_ID/projects/$PROJECT_ID/connections/oauth/start" \
  -H "Authorization: Bearer $ARCHY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "provider": "openai",
  "scope": "user",
  "redirect_uri": "string"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
HEADERS = {"Authorization": f"Bearer {os.environ['ARCHY_TOKEN']}"}
ORG_ID = "<org_id>"
PROJECT_ID = "<project_id>"

payload = {
    "provider": "openai",
    "scope": "user",
    "redirect_uri": "string"
}

response = httpx.request("POST", f"{BASE_URL}/api/v1/orgs/{ORG_ID}/projects/{PROJECT_ID}/connections/oauth/start", headers=HEADERS, json=payload, timeout=60)
response.raise_for_status()
print(response.json())
