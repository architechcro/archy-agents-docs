    LLM providers and models¶

    Bring-your-own provider credentials and the model attachments that decide which model an agent uses.

    This page documents 28 endpoint(s). Replace $ARCHY_API_URL and $ARCHY_TOKEN as described in Conventions.

    Besides the responses listed for each endpoint, any endpoint can return 401 (missing or invalid token), 403 (wrong tenant, role or scope) and 404 (resource not found in your tenant). See Errors.

    GET /api/v1/llm-providers/credentials¶

    List LLM provider credentials

    List the org's credentials, optionally filtered by project scope.

    Authentication: bearer token in the Authorization header.

    Parameters

    Name In Type Required Description
    project_id query string (uuid) no Project id.
    org_id query string (uuid) no Organization id.

    Example

    curl -X GET "$ARCHY_API_URL/api/v1/llm-providers/credentials" \
  -H "Authorization: Bearer $ARCHY_TOKEN"

import httpx

    POST /api/v1/llm-providers/credentials¶

    Create an LLM provider credential

    Create an org-scoped (optionally project-scoped) LLM provider credential. The API key is encrypted at rest and never returned. Requires org-admin.

    Auth: Bearer JWT; org context taken from the token.

    Parameters

    Name In Type Required Description
    org_id query string (uuid) no Organization id.
    project_id query string (uuid) no Project id.

    Request body (application/json, required)

    Field Type Required Description
    provider string yes (min length 1, max length 50)
    display_name string yes (min length 1, max length 255)
    api_key string no
    base_url string no
    api_version string no
    extra_config object no
    project_id string (uuid) no
    is_default boolean no (default false)

    Schema: LlmCredentialCreateRequest

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/llm-providers/credentials" \
  -H "Authorization: Bearer $ARCHY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "provider": "openai",
  "display_name": "Production OpenAI"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
HEADERS = {"Authorization": f"Bearer {os.environ['ARCHY_TOKEN']}"}

payload = {
    "provider": "openai",
    "display_name": "Production OpenAI"
}

response = httpx.request("POST", f"{BASE_URL}/api/v1/llm-providers/credentials", headers=HEADERS, json=payload, timeout=60)
response.raise_for_status()
print(response.json())

    Test Provider Connection

    Test an LLM provider credential with a minimal API call.

    Authenticated and rate limited per user. Makes a 1-token completion request to verify the credential is valid. Timeout: 10 seconds.

    Authentication: bearer token in the Authorization header.

    Parameters

    Name In Type Required Description
    org_id query string (uuid) no Organization id.
    project_id query string (uuid) no Project id.

    Request body (application/json, required)

    Field Type Required Description
    provider string yes
    api_key string no
    base_url string no
    api_version string no
    model_name string no (default "gpt-4o-mini")

    Schema: TestProviderRequest

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/llm-providers/test" \
  -H "Authorization: Bearer $ARCHY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "provider": "openai"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
HEADERS = {"Authorization": f"Bearer {os.environ['ARCHY_TOKEN']}"}

payload = {
    "provider": "openai"
}

response = httpx.request("POST", f"{BASE_URL}/api/v1/llm-providers/test", headers=HEADERS, json=payload, timeout=60)
response.raise_for_status()
print(response.json())

    Responses

    Status Description Body
    200 Successful Response TestProviderResponse
    422 Validation Error HTTPValidationError

    Example 200 response:

    {
  "success": false
