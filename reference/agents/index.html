    PUT /api/v1/orgs/{org_id}/projects/{project_id}/agents/{agent_id}/avatar¶

    Upload agent avatar

    Uploads (or replaces) an agent avatar image in Azure Blob Storage. Stored key convention: orgs/{org_id}/avatars/{agent_id}.{ext}.

    Auth: Bearer JWT; org_id/project_id must match token tenancy.

    Parameters

    Name In Type Required Description
    org_id path string (uuid) yes Organization id.
    project_id path string (uuid) yes Project id.
    agent_id path string (uuid) yes Agent id.

    Request body (multipart/form-data, required)

    Field Type Required Description
    file string (binary) yes

    Schema: Body_upload_agent_avatar_api_v1_orgs__org_id__projects__project_id__agents__agent_id__avatar_put

    Example

    curl -X PUT "$ARCHY_API_URL/api/v1/orgs/$ORG_ID/projects/$PROJECT_ID/agents/$AGENT_ID/avatar" \
  -H "Authorization: Bearer $ARCHY_TOKEN" \
  -F "file=@./document.pdf"

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]

print(response.json())
