    Governance and self-improvement¶

    Change requests, checkpoints, scoped credentials, policy rules and the audit trail.

    This page documents 19 endpoint(s). Replace $ARCHY_API_URL and $ARCHY_TOKEN as described in Conventions.

    Besides the responses listed for each endpoint, any endpoint can return 401 (missing or invalid token), 403 (wrong tenant, role or scope) and 404 (resource not found in your tenant). See Errors.

    Method Path Summary
    POST /api/v1/checkpoints Write a state checkpoint
    GET /api/v1/checkpoints/{correlation_id} Get latest checkpoint and validate integrity
    GET /api/v1/checkpoints/{correlation_id}/history List all checkpoint versions
    POST /api/v1/credentials/issue Issue a time-bound, scope-limited credential
    POST /api/v1/credentials/validate Validate a credential token against a scope
    POST /api/v1/credentials/{credential_id}/revoke Revoke a credential immediately
    GET /api/v1/handoffs/requests List handoff requests
    POST /api/v1/handoffs/requests Create handoff request
    GET /api/v1/handoffs/requests/{correlation_id} Get handoff request by correlation ID
    GET /api/v1/policies/rules List policy rules for org
    POST /api/v1/policies/rules Create a policy rule
    PUT /api/v1/policies/rules/{rule_id} Update a policy rule (increments version)
    DELETE /api/v1/policies/rules/{rule_id} Soft-delete a policy rule (set active=False)
    POST /api/v1/policies/evaluate Evaluate a handoff payload against policy rules
    GET /api/v1/policies/approvals List pending approvals for org
    POST /api/v1/policies/approvals/{approval_id}/decide Approve or reject a pending approval
    GET /api/v1/audit/logs Query audit trail
    GET /api/v1/audit/verify Verify audit chain integrity
    POST /api/v1/restart/{correlation_id} Restart from checkpoint

    POST /api/v1/checkpoints¶

    Write a state checkpoint

    Persist a new append-only checkpoint version for the given correlation_id.

    Authentication: bearer token in the Authorization header.

    Parameters

    Name In Type Required Description
    org_id query string (uuid) no Organization id.
    project_id query string (uuid) no Project id.

    Request body (application/json, required)

    Field Type Required Description
    correlation_id string (uuid) yes
    current_step string yes (max length 256)
    progress_markers object no (default {})
    last_tool_results object no (default {})

    Schema: CheckpointCreate

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/checkpoints" \
  -H "Authorization: Bearer $ARCHY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "correlation_id": "4bcf0d4f-ec9f-5d34-8bce-80fe35d9cad7",
  "current_step": "string"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
HEADERS = {"Authorization": f"Bearer {os.environ['ARCHY_TOKEN']}"}

payload = {
    "correlation_id": "4bcf0d4f-ec9f-5d34-8bce-80fe35d9cad7",
    "current_step": "string"
}

response = httpx.request("POST", f"{BASE_URL}/api/v1/checkpoints", headers=HEADERS, json=payload, timeout=60)
response.raise_for_status()
print(response.json())
