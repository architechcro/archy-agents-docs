    Intake and campaigns¶

    Document intake, PRD and backlog generation, and campaign research.

    This page documents 33 endpoint(s). Replace $ARCHY_API_URL and $ARCHY_TOKEN as described in Conventions.

    Besides the responses listed for each endpoint, any endpoint can return 401 (missing or invalid token), 403 (wrong tenant, role or scope) and 404 (resource not found in your tenant). See Errors.

    Method Path Summary
    POST /api/v1/campaigns/{campaign_id}/research Create Campaign Research
    GET /api/v1/campaigns/{campaign_id}/research/{task_id} Get Campaign Research Status
    POST /api/v1/intake/grill/start Start a grill session (sync handshake)
    POST /api/v1/intake/grill/message Send a message to the grill agent (sync)
    POST /api/v1/intake/grill/restart Restart a grill session (clear history, fresh start)
    DELETE /api/v1/intake/session/{session_id} Delete a grill session and its conversation history
    GET /api/v1/intake/grill/history Get grill session message history
    POST /api/v1/intake/generate/start Trigger output generation (sync handshake)
    POST /api/v1/intake/grill/stream Start or continue a grill session (SSE)
    POST /api/v1/intake/generate/stream Trigger output generation (SSE)
    POST /api/v1/intake/attachments/process Process an uploaded attachment (async)
    GET /api/v1/intake/attachments/{task_id}/status Get attachment processing status
    POST /api/v1/intake/sources/inline Add an inline source to a grill session
    POST /api/v1/intake/kb/create Create an intake KB for a grill session
    POST /api/v1/intake/kb/{session_id}/export Export intake KB as structured JSON

    POST /api/v1/campaigns/{campaign_id}/research¶

    Create Campaign Research

    Start a campaign research task.

    Returns 202 with a task_id. Results are delivered via callback_url or can be polled via GET /campaigns/{campaign_id}/research/{task_id}.

    Authentication: bearer token in the Authorization header.

    Parameters

    Name In Type Required Description
    campaign_id path string yes
    org_id query string (uuid) no Organization id.
    project_id query string (uuid) no Project id.

    Request body (application/json, required)

    Field Type Required Description
    campaign_id string yes (max length 128)
    org_id string (uuid) no
    project_id string (uuid) no
    campaign_description string yes (max length 20000)
    target_url string no
    max_pages integer no (min 1.0, max 20.0, default 5)
    enable_web_search boolean no (default true)
    enable_deep_research boolean no (default true)
    callback_url string no

    Schema: CampaignResearchBody

    Example

    curl -X POST "$ARCHY_API_URL/api/v1/campaigns/$CAMPAIGN_ID/research" \
  -H "Authorization: Bearer $ARCHY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
  "campaign_id": "9a5f74e6-e6c8-5033-aef5-4ec8d7df3091",
  "campaign_description": "string"
}'

    import os
import httpx

BASE_URL = os.environ["ARCHY_API_URL"]
HEADERS = {"Authorization": f"Bearer {os.environ['ARCHY_TOKEN']}"}
CAMPAIGN_ID = "<campaign_id>"

payload = {
    "campaign_id": "9a5f74e6-e6c8-5033-aef5-4ec8d7df3091",
    "campaign_description": "string"
}

response = httpx.request("POST", f"{BASE_URL}/api/v1/campaigns/{CAMPAIGN_ID}/research", headers=HEADERS, json=payload, timeout=60)
response.raise_for_status()
print(response.json())

    Responses

    Status Description Body
    202 Successful Response CampaignResearchResponse
    422 Validation Error HTTPValidationError

    Example 202 response:

    {
  "task_id": "2fd0930e-7ca4-592b-a8dd-3060c6f8cfcc",
  "status": "completed",
  "estimated_seconds": 1
}
